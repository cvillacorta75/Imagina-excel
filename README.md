# Bienvenidos a Excel Fundamentals

Nuestros objetivos son:

Aprender a manejar Microsoft Excel para la gestión de datos\
empresariales. Crear y editar hojas de cálculo de manera eficiente.\
Realizar análisis de datos utilizando fórmulas y funciones. \
Visualizar datos mediante gráficos y tablas dinámicas. \
Proteger las hojas colocando seguridad en ellas.
