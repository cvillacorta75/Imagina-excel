# Bienvenidos a Excel Intermedio

Nuestros objetivos son:

Aprender a manejar funciones y fórmulas en Excel para mejorar la\
eficiencia en tareas diarias. Desarrollar habilidades en la creación y personalización de tablas dinámicas para análisis de datos.\
Implementar gráficos avanzados y personalizados para una mejor visualización de la información. Utilizar herramientas de análisis de datos como segmentaciones y filtros avanzados. Mejorar la capacidad de gestionar y proteger datos con técnicas de seguridad y protección en Excel.
